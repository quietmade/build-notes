# AFTERTONE — public policies

These are the public-facing policy pages for AFTERTONE, adapted from the
live public pages in the private source repository (last updated
23 October 2026). No source code is included here.

| File | What it is |
|---|---|
| [TERMS.md](TERMS.md) | Terms of Service: acceptance, eligibility, acceptable use, invitations, messages, encryption limitations, availability, liability, governing-law placeholders |
| [PRIVACY.md](PRIVACY.md) | Privacy Notice: connection, technical, and message information processed, encryption limits, storage, disclosure, cookies/browser storage |
| [SECURITY-NOTICE.md](SECURITY-NOTICE.md) | Public security page: encryption, key exchange and fingerprint comparison, limitations. Verification status: UNVERIFIED |
| [FAQ.md](FAQ.md) | Frequently asked questions: accounts, invites, refresh/reconnect, encryption, storage, recovery |

## Note on the two security documents

- `../security/SECURITY.md` is the protocol/security-model document for
  reviewers: it describes the design, trust model, and explicit limitations
  in detail.
- `SECURITY-NOTICE.md` here is the shorter public-facing security page
  shown to users. Both say the same thing on the points that matter:
  the key exchange is unauthenticated, both sides must compare the
  fingerprint and press VERIFY before messaging is enabled, and
  verification does not authenticate identity.
