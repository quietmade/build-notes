# AFTERTONE — Assets

## Demo video — manual upload required

The main README embeds `assets/aftertone-demo.mp4`. That file is **not** in this repository yet, because binary files cannot be pushed with the text workflow used for this repo.

To make the README player work:

1. Open this repository on github.com
2. Go to `assets/` (this folder, at the repository root)
3. Upload `aftertone-demo.mp4` (the 22.6-second 1920×1080 demo) via "Add file → Upload files"

Until that upload, the video player in the main README will not play. This is the same pending upload that was already outstanding before the 2026-10-29 rebuild — the rebuild did not change it, and the README does not pretend otherwise.

A 9:16 vertical version (`aftertone-demo-vertical-9x16-1080x1920.mp4`, same demo with blurred fill top and bottom, audio untouched) also exists locally and can be uploaded the same way if a vertical cut is ever needed. It is not referenced by the main README.
